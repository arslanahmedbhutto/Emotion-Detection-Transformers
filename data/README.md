# Dataset

Source: [Emotions Dataset for NLP](https://www.kaggle.com/datasets/praveengovi/emotions-dataset-for-nlp) on Kaggle, by Praveen Govi.

Format: one sample per line, `text;label`.

```
i didnt feel humiliated;sadness
```

| File | Samples |
|------|--------:|
| `train.txt` | 16,000 |
| `val.txt`   | 2,000 |
| `test.txt`  | 2,000 |

Labels: `anger`, `fear`, `joy`, `love`, `sadness`, `surprise`, encoded as 0–5 in that order.
